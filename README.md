# Little Lemon Booking & Reporting System

## Project Overview
This project focuses on the end-to-end development of a robust database system for the Little Lemon restaurant. The goal was to design a scalable database, implement complex business logic via stored procedures, and provide actionable insights through data visualization.

## Key Features
*   **Database Architecture:** A fully relational schema designed in MySQL, documented with a detailed Entity-Relationship (ER) Diagram.
*   **Automated Management:** Custom SQL procedures developed to handle the lifecycle of bookings and inventory checks.
*   **Python Integration:** A database client built in Python to programmatically interact with the MySQL server.
*   **Data Analytics:** An interactive Tableau dashboard used to generate sales reports.
